# Markdown Cheat Sheet

A compact, single-file quick reference for Markdown syntax, including the extra features specific to [Obsidian](https://obsidian.md).

**Tags:** `#reference` `#markdown`

## What's Inside

The cheat sheet (`Markdown Cheat Sheet.md`) covers:

| Section | Topics |
|---|---|
| Headings | H1 through H6 |
| Text Formatting | Bold, italic, strikethrough, inline code, highlight |
| Lists | Unordered, ordered, and task/checkbox lists |
| Links & Images | Standard links, tooltips, images, Obsidian internal links |
| Blockquotes | Single-line, multi-line, and nested quotes |
| Code | Inline code and fenced code blocks, common language identifiers |
| Tables | Basic tables and column alignment |
| Horizontal Rules | The three equivalent syntaxes |
| Footnotes | Reference-style footnotes |
| Callouts | Note, tip, warning, danger, info, summary, and collapsible callouts |
| Embeds | Notes, sections, images, and PDFs |
| Tags | Simple and nested tags |
| Math | Inline and block LaTeX |
| Escaping | Using `\` to display literal syntax characters |
| Quick Reference | One-table summary of the most-used syntax |

## Compatibility

Most syntax in this sheet is standard Markdown and works in GitHub, VS Code, and most other renderers. The following features are **Obsidian-only** and may not render elsewhere:

- `==highlight==`
- `[[Internal Links]]`
- Callouts (`> [!NOTE]`)
- Embeds (`![[Note Name]]`)
- `#tags`
- Math (`$...$` and `$$...$$`)

Each of these is labeled in the file where it appears.

## Usage

1. Download or copy `Markdown Cheat Sheet.md` into your notes folder or repo.
2. Open it in any Markdown editor or viewer. For full rendering of every section, use Obsidian.
3. Use the **Quick Reference** table at the bottom for a fast lookup, or jump to a section for detail and examples.

## Notes

- Code samples are shown inside fenced blocks so the raw syntax stays visible next to its rendered output.
- Nested fenced code blocks use four backticks on the outer fence. Keep that in mind if you edit those sections.
